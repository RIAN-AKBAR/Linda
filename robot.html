Robot Pengangkut Barang

Deskripsi Proyek

Proyek sederhana untuk membuat robot yang dapat mengikuti garis dan mengangkut barang kecil. Cocok untuk pemula yang ingin belajar dasar-dasar robotika.

Bahan yang Dibutuhkan

  • 1x Arduino Uno
  • 2x Motor DC dengan roda
  • 1x Sensor garis (TCRT5000)
  • 1x Driver motor L298N
  • 1x Baterai 9V
  • Kabel jumper
  • Papan acrylic untuk chassis

Cara Membuat

  1. Rakit chassis robot dan pasang motor
  2. Hubungkan motor ke driver L298N
  3. Hubungkan sensor garis ke Arduino
  4. Upload program berikut ke Arduino:
// Contoh kode sederhana
void setup() {
  pinMode(5, OUTPUT); // Motor kiri
  pinMode(6, OUTPUT); // Motor kanan
  pinMode(A0, INPUT); // Sensor garis
}

void loop() {
  if (digitalRead(A0) == HIGH) {
    // Jalan lurus
    digitalWrite(5, HIGH);
    digitalWrite(6, HIGH);
  } else {
    // Belok kanan
    digitalWrite(5, HIGH);
    digitalWrite(6, LOW);
  }
}

Tips

  • Gunakan permukaan putih dengan garis hitam tebal
  • Mulai dengan beban ringan (100-200 gram)
  • Pastikan baterai cukup kuat untuk motor
